# Week 2: Device-to-Device P2P Transport Layer

We implemented a peer-to-peer device-to-device transport simulator in [`sync/transport.py`](file:///C:/Users/verne/Projects/rotm/sync/transport.py) using framed TCP sockets over localhost to mimic physical Bluetooth/Wi-Fi Direct transaction exchange between offline mobile nodes. The transport layer defines a length-prefixed JSON protocol for identity handshakes (`HANDSHAKE` / `HANDSHAKE_ACK`) and bidirectional transaction synchronization (`SYNC_TXNS` / `SYNC_ACK`), enabling two isolated `DeviceNode` instances to establish local socket listeners, exchange signed transaction histories, detect double-spend conflicts upon ledger merge, and trigger local LLM risk assessments. The implementation was validated via a multi-process simulation script [`sync/socket_demo.py`](file:///C:/Users/verne/Projects/rotm/sync/socket_demo.py) and a dedicated unit test suite in [`tests/test_transport.py`](file:///C:/Users/verne/Projects/rotm/tests/test_transport.py) covering successful socket connection, bidirectional ledger synchronization, transaction deduplication, and transport-level double-spend conflict detection.
